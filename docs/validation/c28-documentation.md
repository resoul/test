- `docs/weave-analysis.md` целиком — это исторический анализ источника
  (~1200+ строк), его тело не переписывалось построчно под текущее API:
  риск внести ошибку в документ, который уже явно помечен как исторический,
  выше пользы. Только пометка в начале усилена.
- `docs/decisions.md` — уже полный, ничего не добавлялось.
- `api/*.json` — уже актуален, `check_api.py` подтвердил без `--update`.
- Реорганизация `docs/validation/screenshots/` — отдельная незавершённая
  работа пользователя, не тронута.

## Итог этапа

Это последняя карточка `docs/implementation-plan.md`. Release/tag/publish не
входят в план — отдельное действие после готовности этапа, которое явно не
предпринималось здесь. Два пункта приёмки остаются открытыми и названы явно
(не скрыты): физическая матрица на iOS/iPad/tvOS недоступна (нет устройств),
и CI-workflow не прогонялся на настоящем hosted-раннере (нет git remote).
