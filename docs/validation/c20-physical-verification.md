# C20 — Физическая проверка и устранение дефектов хоста

## Состав и окружение

- **Платформа**: macOS (Apple Silicon arm64, macOS 14+).
- **Схема**: `Playground-macOS` из `Playground/Playground.xcodeproj`.
- **Сценарий**: `S01_SingleNode` в режиме `nativeBounds` (окно 720×640).

## Обнаруженные и исправленные дефекты

При первом запуске чисто программного приложения без Storyboard / Info.plist MainNib
вскрылись особенности инициализации AppKit:
1. Синтезированный компилятором `@main` для `NSApplicationDelegate` вызывает `NSApplicationMain`,
   который ищет `NSMainNibFile`. Из-за отсутствия nib-файла экземпляр `AppDelegate` не
   создавался и `applicationDidFinishLaunching` не выполнялся.
2. По умолчанию у непакетированного процесса отсутствует оконная политика активации
   (`setActivationPolicy(.regular)`), из-за чего окно не отображалось в Dock и не
   выводилось поверх других окон.
3. Окно по умолчанию создавалось в нижнем левом углу (0, 0), вне активной зоны фокуса.

**Исправление** в [PlaygroundApp.swift](../../Playground/macOS/PlaygroundApp.swift):
- Объявлен явный `@MainActor static func main()`, где `AppDelegate` создаётся, сохраняется в сильной ссылке и назначается в `NSApplication.shared.delegate`, после чего запускается `app.run()`.
- Выставлена регулярная политика активации `NSApp.setActivationPolicy(.regular)`.
- Окно центрируется (`window.center()`) и выводится на передний план (`NSApp.activate(ignoringOtherApps: true)`).

## Результаты визуальной проверки (S01–S15)

В [PlaygroundApp.swift](../../Playground/macOS/PlaygroundApp.swift) реализована интерактивная панель инструментов (`NSToolbar`) с возможностью:
- переключения любого сценария на лету через выпадающий список (`NSPopUpButton`);
- пошаговой навигации `◀ Prev` / `Next ▶`;
- пакетного экспорта всех окон в PNG (`--export-all` / `📸 Export All`).

### Проверены все 15 сценариев:
1. **S01 (SingleNode)**: одиночная синяя карточка 120×80 pt с отступами 16 pt.
2. **S02 (RowOfThree)**: ряд из 3 цветных блоков 72×72 pt с `gap = 8`.
3. **S03 (Column)**: вертикальная колонка блоков с отступами.
4. **S04 (Justify)**: распределение `spaceEvenly` вдоль главной оси.
5. **S05 (Align)**: выравнивание `flex-start`, `center`, `flex-end` по поперечной оси.
6. **S06 (Gap)**: корректная работа flexbox gap для строк и колонок.
7. **S07 (PaddingMargin)**: вложенные отступы и внешние поля.
8. **S08 (Grow)**: пропорциональное распределение свободного пространства (`flexGrow`).
9. **S09 (Sizes)**: min/max/fixed constraints.
10. **S10 (Nesting)**: 4 вложенных цветных контейнера (синий, зеленый, оранжевый, розовый) с `padding = 12`.
11. **S11 (Absolute)**: абсолютное позиционирование поверх нормального потока.
12. **S12 (Wrap)**: перенос элементов при нехватке ширины строки (`flexWrap = .wrap`).
13. **S13 (RTL)**: инверсия направления главной оси при `layoutDirection = .rightToLeft`.
14. **S14 (SafeArea)**: корректная трансляция системных insets.
15. **S15 (DynamicMutation)**: динамическая мутация (таймер сессии раз в секунду добавляет/удаляет элемент без утечек).

Скриншоты всех 15 сценариев экспортированы и сохранены в [docs/validation/screenshots/](screenshots/):
