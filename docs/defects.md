# Реестр найденных дефектов

Каждый найденный дефект — строка здесь в момент обнаружения, до исправления: компонент, что
было не так, как найден, статус. Исправление дописывает коммит; неисправленное остаётся
**открыт** с тем, где закрыть. Порядок — по дате обнаружения.

Нумерация общая с реестром Trellis, где Espalier начинался (папка `v22/`, с 2026-09-26 — корень репозитория
[resoul/test](https://github.com/resoul/test/blob/trellis-final/docs/defects.md)): #1–#106 — дефекты
Trellis, в том числе #95–#106 — расхождения старого движка с Chromium, от которых отталкивался
новый. Отсюда — дефекты Espalier с #107; новые продолжают нумерацию с #154. Хэши коммитов в
статусах — из истории resoul/test.
