# PreviousLayoutEngine

Замороженная копия старого движка раскладки — `Sources/TrellisCore` из
[resoul/test](https://github.com/resoul/test) на ревизии
`2d20d678580813855de0f07c22d02c0da90fcce5`, без изменений. Нужна только бенчмарку
`LayoutBench` для сравнения «новый движок против старого».

Код не сопровождается и не правится: сравнение имеет смысл, пока старый движок один и тот же.
Правила пакета (`AGENTS.md`: изоляция, имена, документация API) к нему не применяются — это
чужой код для замера, а не часть библиотеки.
